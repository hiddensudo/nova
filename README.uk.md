<h1 align="center">Nova Control</h1>
<p align="center"><strong>Апаратні налаштування гарнітури й мікшер застосунків для Linux.</strong><br>Rust · SteelSeries Arctis · PipeWire</p>
<p align="center"><a href="#встановлення-й-оновлення">Встановлення</a> · <a href="#апаратний-eq">Пресети</a> · <a href="docs/headsets.md">Гарнітури</a> · <a href="README.md">English</a></p>

Нативний застосунок для SteelSeries Arctis Nova 7 Wireless Gen 2 через USB-донгл `1038:227e`. Слайдер Mic Sidetone має чотири апаратні позиції **Off, Low, Medium і High**. Панель зчитує рівень автоматично. Зміна застосовується після відпускання повзунка. Кнопка **Зберегти в гарнітурі** або `nova-control sidetone save` записує поточні налаштування пристрою.

## Встановлення й оновлення

### Готова збірка

Завантаж архів для Linux x86-64 із [GitHub Releases](https://github.com/hiddensudo/nova/releases). Розпакуй його й запусти інсталятор через Python 3.9 або новіший.

```sh
python3 install.py
```

Після цього **Nova Control** доступний у меню застосунків і пошуку KDE. Для оновлення виконай ту саму команду з новішого архіву та відкрий застосунок знову, якщо вікно старої версії ще працює. Встановлена копія в `~/.local/bin/nova-control` працює незалежно від архіву. Мінімальну версію glibc конкретної збірки вказано в `BUILD.txt`.

Щоб видалити застосунок, вимкни мікшер і прибери `nova-control-mixer.desktop` з каталогу `autostart` у своєму `XDG_CONFIG_HOME` або `~/.config`. Потім прибери `~/.local/bin/nova-control` і `nova-control.desktop` із `~/.local/share/applications` або з каталогу `applications` у своєму `XDG_DATA_HOME`.

### Встановлення через Docker

Якщо Docker запущений і є Python 3.9 або новіший, відкрий термінал у папці проєкту та виконай:

```sh
./install
```

Скрипт збере Nova в Docker, встановить її для поточного користувача й прибере кеш тимчасового збирача. Для встановлення правила доступу до USB скористайся `./install --udev` і перепідключи донгл. Для допомоги крок за кроком скопіюй [промпт встановлення](docs/install-prompt.md) у ChatGPT або Claude.

## Збірка з коду

Потрібні Rust 1.95+, Python 3.11+, C-компілятор та pkg-config. Пакунки для Debian і Ubuntu перелічено в [README](README.md#build-from-source). У папці з кодом виконай `python3 install.py` для збірки й встановлення. Ця команда також оновлює встановлену копію після `git pull --ff-only` або розпакування новішого коду.

- `cargo build --release --locked` збирає без встановлення.
- `cargo test --locked` перевіряє Rust-код без відкриття вікна.
- `python3 scripts/package.py` створює готовий Linux-архів, архів коду й контрольні суми в `dist/`.

Додаткові команди і параметри пакування є в [README](README.md).

## Доступ до донгла

Встанови правило udev, якщо застосунок повідомляє про відсутність прав доступу до донгла.

```sh
sudo install -m 0644 packaging/linux/70-nova-control.rules /etc/udev/rules.d/70-nova-control.rules
sudo udevadm control --reload-rules
```

Після цього перепідключи донгл. Застосунок запускається від звичайного користувача.

## Апаратний EQ

Щоб додати 385 профілів із [публічного архіву Sonar](https://github.com/loteran/Arctis-Sound-Manager/blob/84545e49839e44137ce06b6e10df807ad0ad2440/presets_manifest.json), запусти:

```sh
python3 scripts/fetch-gg-presets.py
```

У вкладці EQ натисни **Перечитати каталог**. Nova застосовує сумісні криві відтворення. Профілі мікрофона й криві з непідтримуваними фільтрами відображаються в списку без можливості застосувати їх до відтворення. Власні JSON можна покласти в `~/.config/nova-control/presets/` або `$XDG_CONFIG_HOME/nova-control/presets/`.

Вкладка **EQ** показує активний профіль і перемикає чотири локальні пресети Flat, Bass Boost, Focus та Smiley. JSON-профілі Nova Control і сумісні пікові криві Sonar можна застосувати до EQ гарнітури. Частоти округлюються до 1 Гц, підсилення до 0,1 дБ, Q до 0,001. Ефекти Sonar поза параметричною кривою залишаються в Sonar.

```sh
nova-control eq list
nova-control eq get
nova-control eq select Focus
nova-control eq export ~/nova-eq.json
nova-control eq import ~/nova-eq.json
```

Зміни EQ перевіряються повторним читанням із донгла. Поточна крива лишається активною до наступної зміни або вимкнення. [Формат апаратного EQ Gen 2](https://github.com/loteran/Arctis-Sound-Manager/issues/146)

Редактор у вкладці **EQ** редагує частоту, підсилення й Q кожної з десяти пікових смуг. **Прослухати** застосовує чернетку в гарнітурі на поточну сесію. **Відновити попередній** повертає профіль, з яким було відкрито редактор. **Зберегти в гарнітурі** або `nova-control eq save` надсилає команду збереження поточних налаштувань.

## Мікшер PipeWire

У списку застосунків показуються локальні іконки програм, зокрема Steam-ігор із встановленими ярликами. Якщо іконку не знайдено, показується літера назви.

У вкладці **Мікшер** натисни **Увімкнути мікшер**. Для кожного каналу є окрема гучність. Щоб призначити канал застосунку, запусти в ньому відтворення й вибери канал зі списку. Призначення та рівні зберігаються в `$XDG_CONFIG_HOME/nova-control/mixer.json` або `~/.config/nova-control/mixer.json`. Стан увімкнення також зберігається. Після входу в Linux встановлена версія запускає фоновий мікшер, який відновлює збережені налаштування, щойно з’явиться аудіовихід гарнітури. Кнопка **Вимкнути мікшер** вимикає маршрутизацію й запам’ятовує цей стан.

Потрібна системна бібліотека libpulse (libpulse0 на Debian та Ubuntu) і запущений `pipewire-pulse`. Мікшер продовжує працювати після закриття вікна. Для окремого запуску в терміналі є `nova-control mixer run`. Вимкнення прибирає віртуальні канали.

У мікшері можна увімкнути **Фізичне коліщатко ChatMix** і вибрати будь-які два канали. Ліва позиція коліщатка відповідає першому каналу у списку. Третій канал і загальна гучність гарнітури зберігають власні рівні. Через CLI використовуй `nova-control mixer chatmix Game Media`. Поточну апаратну позицію читає `nova-control mixer dial`.

## Налаштування пристрою

Вкладка **Пристрій** показує заряд і стан заряджання, регулює рівень мікрофона, таймер автовимкнення та яскравість LED вимкненого мікрофона. Команди термінала `nova-control settings get`, `nova-control settings mic 6`, `nova-control settings sleep 30`, `nova-control settings led 2` і `nova-control settings save`.

## Інтерфейс 0.3

Огляд показує підключення, заряд, рівні каналів і швидкі дії. Sidetone доступний у секції Мікрофон у Мікшері, у верхній панелі й у меню системного трея. Окрема кнопка збереження Sidetone з’являється після зміни рівня.

У EQ перетягуй точки на графіку або задавай точні значення Гц, дБ і Q. A/B застосовує до гарнітури попередню або поточну криву для порівняння на слух. У списку локальних пресетів є пошук і обране.

Мікшер має кольорові горизонтальні канали, mute, індикатори активних потоків і смугу ChatMix. Власний канал можна додати кнопкою «Додати канал», а застосунок призначити через меню або перетягуванням. Старі маршрути, рівні Game / Media / Chat і пара ChatMix читаються з наявного mixer.json.

У Пристрої можна обрати українську чи англійську мову, вимкнути окремі типи системних сповіщень і призначити глобальну клавішу циклу Sidetone. Для сповіщень потрібен notify-send, для глобальної клавіші — підтримка XDG Global Shortcuts у середовищі стільниці.

## Навігація 0.3.1

Mouse 4 повертає на попередню панель, Mouse 5 переходить уперед. Мікрофон об’єднано з Мікшером. Канали займають повну ширину, а застосунки розташовані нижче. Перетягуй канал за маркер зліва або обери переміщення вище / нижче в його меню. Порядок вбудованих і власних каналів зберігається.

ChatMix зчитується в окремому потоці з цільовим інтервалом 25 мс. Запит заряду й стану заряджання виконується кожні 350 мс, під час заряджання іконка батареї анімовано заповнюється.

## Запуск і закриття 0.3.2

Повторний запуск відкриває вже запущене вікно. Хрестик закриває вікно. Для згортання в системний трей є окрема кнопка у верхній панелі. Помилка зайнятого HID-інтерфейсу показується у вікні без повторних системних сповіщень.

## Іконка Nova

Застосунок використовує чорно-білий знак «Імпульс». Інсталятор додає SVG, іконки малих розмірів і символічний варіант для трея. Для видалення іконок прибери файли nova-control.png, nova-control.svg і nova-control-symbolic.svg з відповідних підкаталогів ~/.local/share/icons/hicolor або свого XDG_DATA_HOME/icons/hicolor.

### Звук працює, а керування гарнітурою недоступне

Керування використовує окремий USB-інтерфейс. Якщо його зайняв інший менеджер гарнітури, закрий його і перевір, чи працює його фоновий сервіс. Наприклад, Linux Arctis Manager може запускати `arctis-manager.service` навіть без відкритого вікна. Після звільнення інтерфейсу Nova Control автоматично відновлює читання. Вимикаючи інший менеджер, перевір, чи не використовуєш його віртуальні канали.


## Окремий виконуваний файл

```sh
docker build --target binary --output type=local,dest=dist .
./dist/nova-control
```

Збірка потребує Docker. Виконуваний файл запускається у звичайному графічному сеансі Linux із glibc 2.36+ без Rust чи Python. Потрібна системна бібліотека libpulse, а для мікшера — запущений PipeWire Pulse. Англійська є мовою за замовчуванням. Українську можна вибрати в налаштуваннях. [Підтримка гарнітур](docs/headsets.md)

[Дослідження апаратного Sidetone](docs/sidetone-research.md) пояснює, які налаштування діють на USB-мікрофон і які можливості відомі для моніторингу.
